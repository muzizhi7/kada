# Support / 使用反馈

Kada is a source preview, maintained on a best-effort basis. Start with [README](README.md), [usage](docs/USAGE.md) and [tryout](docs/TRYOUT.md).

- Bugs: [bug report](https://github.com/muzizhi7/kada/issues/new?template=bug_report.yml)
- Suggestions: [feature request](https://github.com/muzizhi7/kada/issues/new?template=feature_request.yml)
- Vulnerabilities: follow [SECURITY.md](SECURITY.md), not a public issue.

For connection failures, check Node >=24.7, your selected model/provider, the local backend version and sanitized error output. On macOS, the desktop companion also needs Swift command-line tools. A running older backend must be handled deliberately; changing the UI does not upgrade a live daemon.

Useful feedback includes the task requirements, usable/missing deliverables, corrections after confirmation, estimated cost, elapsed time and whether you would use Kada for a second task. Record failures as well as successes.

Never attach .env, harness.config.json, .harness, SQLite sessions, local API tokens, supplier keys or unredacted personal files. Share a synthetic work copy and a short relevant error excerpt instead.
