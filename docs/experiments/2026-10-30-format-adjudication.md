# 格式代理检查的统一复核

原始机器评分保存不动。复核对所有四次执行使用相同规则，另存 `adjudication.json`，同时公布原分与复核后分数。

1. TASK 对 `source_file` 要求可以定位到真实文件，但未规定相对根目录。允许相对工作区、claims 所在目录，或 inputs 中唯一可定位的文件简称。无法唯一定位仍不通过。没有使用约定列名、把本地定位文字写进 url 而非真实网页 URL，仍然计为接口缺陷，不自动更名或补 URL。
2. 报告要求讨论风险与数据缺口，不要求必须出现字面“风险”。“局限”“缺口”“不能回答什么”等实际表达同一内容的章节应计入结构覆盖；人工部分仍独立核对其内容质量。

这两项只纠正机械代理与任务语义之间的偏差。数值正确答案、权重、健壮性测试、费用及介入记录均不改变，不把机器格式分数的细微差异解释为能力排名。
