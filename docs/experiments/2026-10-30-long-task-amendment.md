# 提示词组的实施修正

修正发生在预试提示词组结束、当前实现组执行中、任何独立质量评分之前。

预试将 Goal-Driven 模板放入 agent instructions，初始用户输入为共同任务全文。该组结束时没有创建子 Agent，不能据此把结果当作原文主从结构的效果。保留它的完整记录与消耗，不按交付得分选择保留与否。

正式提示词组按仓库 Usage 将完整模板作为初始用户消息，Goal 填入同一任务全文，Criteria 指向其中相同标准和 acceptance.json。共同系统指令、工具、模型、材料、预算和评分器不变。此组单独补跑一次；原生与当前实现使用原有执行，不增加质量反馈。若仍未形成主从结构，明确报告遵从性限制，不不断调提示词直到出现理想结果。

预试实际消耗也计入本次实验总费用；正式三组的成本单独列出。正式提示词组后运行，顺序和缓存可能影响费用，因此必须同时列出缓存/非缓存 token，不能仅据单次费用宣布优势。

补跑前只修正了观察脚本读取 Pi storage 的 TypeScript 公共接口用法：保存 openNodeSqliteStorage 返回的句柄，而不是读取 Harness 对象的非公开 storage 属性。这不修改模型指令、工具或生产实现。原预试及当时已启动的其他组使用已归档的 executed-runner.ts，不因磁盘脚本更新而热切换。

评分器、原始任务、固定验收与生产执行代码保持冻结。最终报告须同时披露预试、正式组、实际子 Agent 数量，以及不提供五分钟后台看门狗的共同接口限制。
