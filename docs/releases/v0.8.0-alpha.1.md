# Kada v0.8.0-alpha.1 — First public source preview

Kada 是基于 Pi 的目标驱动 Agent。它从你已有的本地 Agent 配置、Skills 和任务材料出发，与你确认目标、交付、范围与预算，再在后台推进，交回文件、实际检查结果和限制。这个公开版本提供环境发现；更深入的用户工作记忆仍在开发验证中。

## Included / 本版包含

- 终端聊天与可选 macOS 原生桌面伙伴。
- 一次确认、后台执行、暂停/恢复、预算与版本绑定的命令核验。
- Pi 原生 Skills、本机 Agent/Skill/插件元数据发现。
- Kada C6 双模块像素形象、中文输入、添加资料和自定义外观。
- 中英文安装说明、MIT 许可证、数据流说明和贡献模板。

## Download and run

Download `kada-0.8.0-alpha.1-source.tar.gz` or `.zip` and verify with `SHA256SUMS.txt`, then extract and run from its root:

```sh
npm ci --ignore-scripts
cp -n .env.example .env
# Edit .env with your provider, model ID and key.
npm run chat
# macOS 13+ with Swift command-line tools:
npm run pet
```

Requires Node.js 24.7+. These are **source archives**, not standalone desktop installers. Dependencies, model keys and Swift tools are not bundled. The model-free `npm run demo` works without a provider key. Package/runtime compatibility version is 0.8.0; this GitHub tag marks its public alpha preview.

## Validation

Local verification includes product typechecking/build, 113 product tests, native core and window smoke, and dependency audit. Remote CI status belongs to the associated commit and must be checked separately. Scripted-model tests do not establish real-model task quality.

## Known limits

The shell has current-user permissions and no OS sandbox. Cloud-model requests may include task material read by tools. Checks do not prove complete semantic correctness. Real computer-use and automatic learning are off by default. No signed installer, auto-update or Windows verification. Hour-scale reliability and consistent gains over Pi remain unproven.
