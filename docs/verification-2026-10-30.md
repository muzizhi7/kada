## 原生 Pi 对照

复现：`npm run test:compare`。同模型、同一 Pi 版本、相同原生终端/文件工具和本地权限、相同输入、输出条件与压缩配置。原生 Pi 在自然返回后检查文件；扩展在已配置检查通过后标记完成。扩展独有目标工具和策略，因此 prompt 与工具描述会增加。

任务为筛选 JSON 输入、分类计算、输出结果与中文说明，结果固定为 71。每组一次，顺序为 Pi 后扩展；无故障注入，无中断，不构成统计结论。

| 结果 | 原生 Pi | v0.3 扩展 |
|---|---:|---:|
| 输出条件通过 | 是 | 是 |
| 用户续跑消息 | 0 | 0 |
| 用时 | 8.310 秒 | 10.963 秒 |
| 累计 token（含缓存） | 7,259 | 20,456 |
| 估算费用 | $0.001688 | $0.002741 |

简单任务里扩展增加约 2.65 秒、$0.00105 的开销，不能据此宣称更高完成率或更低成本。故障注入证明了自动修正机制按预期工作，还需要对中断、多阶段、交付不通过等真实长任务做更多相同条件的对照，才足以证明项目增量。
