[已完成的真实案例](../../docs/showcase-2026-10-31-handover.md)含实际产物、全部费用、初次准备缺陷与1次开发者文档反馈。[completed/](completed/README.md)是本次最终模型产物的代码/测试/使用说明副本，供阅读；原始自动交付快照另存。它是已知开发示例，不是未见过的评测题。

```sh
# 已配置模型后，执行一次生产确认到交付和一次相同模型/工具/执行预算的Pi基线

```
