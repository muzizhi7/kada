# 本地任务方法

这是可按需读取的工作说明，使用现成 Pi 工具执行，无额外加载器。按任务读取相关一份；不要为不相关的任务增加流程。

- [数据与研究交付](data-research.md)：从资料、计算到表格/图/报告，核对数值与引用。
- [批量文件工作](file-work.md)：整理、转换与归档，核对映射、完整性和中断后的实际状态。
- [代码修改与交付](code-work.md)：复用既有测试、保留原行为与类型、交付实际源码及验证限制。

先读取 task_status 中已确认的交付、范围、标准、预算与历史结果。普通阶段转换不要求用户继续确认。必要条件确实缺失、超出授权或预算耗尽时如实说明。

`task_verify` 通过 Pi bash 执行检查，记录输入/产物哈希并返回 proof ID。它证明该次命令与观察到的文件版本相符，不自动证明测试合理或结论正确。修改文件后重新检查；不要降低条件、写入伪造通过值或重复已有副作用来凑结果。

存在既有测试或提供的核对程序时，在命令型标准的 verification 中列明命令、需要保持原样的 inputs 和待核对 outputs；确认时固定命令及 inputs 原字节。目录可直接绑定，包含其文件、成员路径与空目录。空文件和空目录本身不是失败；需要内容非空时由明确的业务检查判断。交付目录中的符号链接/特殊文件仍不自动遍历，按任务要求处理或打包。

最终提交覆盖每个确认标准。命令型标准引用当前通过的 proof ID；内容型标准记录具体自检证据，未核实如实标明。自检与独立复核分开说明。
