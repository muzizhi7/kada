# 批量文件工作

1. 从已确认目录和操作范围出发，先列文件并抽查格式。准备源文件到目标文件的映射，处理重名、重复与不支持格式；有无法自行决定的破坏性冲突才询问。
2. 按授权执行，不隐含删除原件或覆盖无关文件。批次产物和必要的映射/处理结果留在工作区；保留明确的失败项，不用“处理过部分文件”代替全部完成。
3. 核对文件数量、映射覆盖和内容完整性。按任务对照大小、哈希或转换后的语义结果；哈希不同不自动等于转换失败，先确认要求。
4. 用实际检查程序验证映射与关键结果。已有独立核对程序在确认说明的 verification 中固定命令、原始核对程序/源目录（inputs）和待交付目录（outputs）；新生成的映射是输出。检查新目录重建、输入增删改后的覆盖与过时目标清理；若要求确定性，比较整个交付包/ZIP字节，不只比较解压后的内容。空文件、空目录、真实零和缺失值分别处理，不能因空就丢弃。明确哪些是自检，不能手改清单伪造成功。
5. 中断后先检查文件、输出及进程状态，确定哪些动作已生效，再继续剩余部分。尤其不能盲目再次移动、追加或重新计数。不能判断外部效果时明确保留问题。

仅在任务目标相关时使用本方法。普通批次交接不要求用户再说继续；完成时按确认标准交付实际结果、失败项和验证范围。
